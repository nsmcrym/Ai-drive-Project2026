# AI質問機能 実装計画

[要件定義書](requirements.md) と [設計書](spec.md) を基に、授業内で行う標準課題を9段階に分ける。第5回は TASK-01〜05 でサーバーとDB、第6回は TASK-06〜09 で画面・異常系・公開条件を確認する。各段階で期待結果と実測結果を照合してから次へ進む。環境上の制約で実行できない確認は未実施と記録する。

以下の対応欄では、2件目以降の要件ID・設計IDの共通接頭辞 `REQ-AI-`・`DES-AI-` を省略する。
