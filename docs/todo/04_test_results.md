## ローカルの実装確認

2026-11-18 15:40（JST）。ビルド済みアプリを `http://127.0.0.1` の一時ポートで起動し、PostgreSQL接続をテスト用の代替処理に差し替えてHTTP応答を確認した。

| 対象 | 結果 |
| --- | --- |
| ビルドとJS構文 | `npm run build` と `node --check public/todo/todo.js` が成功 |
| 既存ルートと画面配信 | `/`、`/api/db-check`、`/db-sample/new`、`/todo`、`/todo/todo.js` が `200` |
| REQ-01 一覧 | 0件で `200` と空配列 |
| REQ-02 登録 | `201`、空白除去、初期状態が未完了、UTCの日時文字列を確認。壊れたJSON・型違いで `400`、空白のみ・101文字で `422` |
| REQ-03 完了切替 | 完了・未完了への更新で `200`。不正ID・項目欠落で `400`、削除済みIDで `404` |
| REQ-04 削除 | 本文なしの `204`、再削除で `404`、再取得で空配列 |
| DBエラー | テスト用にSQL実行失敗と接続失敗を再現し、`500 INTERNAL_ERROR` と `503 DB_UNAVAILABLE`、空配列の `details` を確認 |
